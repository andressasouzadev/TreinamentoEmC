# Questão 15

**Alternativa correta:** **c) Uma diretiva especial para o pré-processador C, executada antes da compilação.**

---

## Explicação:
Todas as linhas que começam com o caractere `#` não são comandos C compilados diretamente para linguagem de máquina; são diretivas destinadas ao pré-processador, que atua antes do compilador propriamente dito.
