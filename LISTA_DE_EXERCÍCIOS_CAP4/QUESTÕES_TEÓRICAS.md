# Questão 01

Resposta: Um vetor é uma sequência de elementos do mesmo tipo, armazenados em posições consecutivas da memória. Cada posição é acessada por um índice.

# Questão 02

Resposta: A principal diferença é que o vetor é unidimensional, enquanto a matriz é bidimensional ou multidimensional. A matriz é formada por linhas e colunas.

# Questão 03

Resposta: Em C, os índices começam em 0. Por isso, o primeiro elemento de um vetor está na posição 0, o segundo na posição 1 e assim por diante.

# Questão 04

Resposta: A declaração de um vetor segue a forma `tipo nome[tamanho];`. Por exemplo: `int notas[5];` cria um vetor com cinco posições inteiras.

# Questão 05

Resposta: A matriz é útil quando precisamos armazenar dados em tabela, como notas de alunos em várias disciplinas ou valores organizados em linhas e colunas.

# Questão 06

Resposta: Em C, uma string é um vetor de caracteres terminado por `\0`. Por isso, ela pode ser tratada como um conjunto de letras armazenadas em sequência.

# Questão 07

Resposta: `char nome[20];` reserva espaço para 20 caracteres, enquanto `char nome[] = "Maria";` cria o vetor automaticamente com tamanho suficiente para armazenar a palavra e o caractere nulo final.

# Questão 08

Resposta: O `scanf` lê dados digitados pelo usuário e guarda em variáveis. Quando usamos `scanf("%s", nome);`, o nome do vetor já é um ponteiro para o primeiro elemento, então não precisamos usar `&`.

# Questão 09

Resposta: `sizeof` retorna o tamanho em bytes de uma variável ou tipo. Em vetores, ele serve para descobrir quantos bytes o vetor ocupa no total.

# Questão 10

Resposta: Para percorrer um vetor, usamos laços como `for`. Esse tipo de estrutura facilita a leitura, a escrita e a manipulação de todos os elementos do vetor.
